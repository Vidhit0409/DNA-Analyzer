# DNA Sequence Analyzer

This is a simple Python project that analyzes a DNA sequence.

## Features
- Counts number of A, T, G, C
- Calculates GC content
- Shows total length of DNA

## How to Run
1. Open terminal
2. Run:
   python dna_analyzer.py
3. Enter DNA sequence when asked

## Example Input
ATGCGTA

## Example Output
Length: 7
A: 2
T: 2
G: 2
C: 1
GC Content: 42.85%
